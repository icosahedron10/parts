# Full-exam regressions

`full-exam-2026-11-03.jsonl` contains sixteen original query-only cases selected after the first complete exam: four handoff serialization failures, eight jumper-harness queries affected by an instruction-product URL, and four track-frame queries where navigation indexes were mistaken for parts assemblies. It contains no expected answers or routing hints.

The frozen benchmark answer key is used only by the post-run scorer. This subset diagnoses fixes; its score must never be combined with an earlier exam to manufacture a passing full-exam result. New full exams use all 400 original questions and fresh conversation state.
